no revision). Source asset: 269676681 bytes; its BLAKE2B equals the
`linux-cachyos/.SRCINFO` checksum at packaging commit `66666177`.
Genpatches `7.3-2` matches local `gentoo-sources-7.3.1`; it differs from

## Upstream audit and difference from previous pass

Both sources and kernel ebuilds audited independently against the pinned
PKGBUILDs, variant directories, selected patches and configs.

- Configs `523baf9` -> `66666177`: all seven 7.3 variant PKGBUILDs keep the
  same option keys and defaults; only `_minor`, `_tagrel` and checksums change.
  Variant directories are identical. `linux-cachyos-hardened` still targets
  7.2.11 and `linux-cachyos-lts` 6.18.55. Base and deckify configs are
  byte-identical to the previous pin. No USE flag added, removed or renamed;
  `metadata.xml` unchanged.
- Patches `89bb22dec` -> HEAD `5429485`: the 7.3 tree only gains
  `misc/nvidia-580xx/*`, which no 7.3.1 PKGBUILD references. BORE, PRJC, RT-i915,
  ACPI-call, handheld and dkms-clang bytes at `89bb22dec` equal the 7.3.1
  `.SRCINFO` BLAKE2B checksums; the AUFS patch is unchanged. The patch pin is
  kept because renaming identical distfiles adds no coverage;
  `update_ebuild.py` would pin HEAD.
- Overlay patches: the TAS2783 backport is still needed (`cachyos-7.3.1-1`
  keeps the unconditional `select SND_SOC_TAS2783_SDW`) and applies cleanly.
  The thin-dist AutoFDO/Propeller fix still applies (one context fuzz, as on
  7.3.0). The 7.3.0 MuQSS Kconfig rebase is reused unchanged.
- Binary: the mirror has no 7.3.1 packages. Retained bin 7.3.0-r3, 6.18.55-r1
  and hardened 7.2.9-r1 still match the mirror; no bin change.
  `virtual/dist-kernel-7.3.1_p0` lists only the source-built kernel.
- App-admin: `cachyos-settings` 1.4.1 and `ananicy-cpp` v1.2.0 are the latest
  tags; CachyOS rules HEAD `03ef03fb` equals the pin. No change.

underscores for HZ, tickrate, preemption, hugepage and generic-v flags.

## Validation

Isolated `PORTAGE_CONFIGROOT` (no host `package.use`, env hooks or user
patches). 35 `clean prepare` + `olddefconfig` + `tests/test-source-features.py`
cases (17 sources, 18 kernel): BORE, EEVDF, BMQ, PDS, MuQSS 1000 Hz full,
MuQSS 100 Hz periodic lazy + AUFS, RT, RT-BORE, deckify, AUFS, KCFI, full,
thin-dist and no LTO, staged ZFS, server preset, `-bbr3 -per-gov` and kernel
GCC; scheduler patches applied at `--fuzz=0`. Default sources `clean package`
produced a binary package; installed-image assertions pass. No kernel compile,
`modules_prepare` or boot test.
