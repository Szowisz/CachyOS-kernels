# CachyOS 7.3.0-r1 feature inventory

Target: `cachyos-7.3.0-2` (Gentoo revision r1), genpatches `7.3-1`.
Pins: configs `f8d566ed16e186f57f46df7bf1bf22a285d3be6c`, patches
`6847663965a6f8edeca780385148528bdf184963`, ZFS
`fb48c76e17d3e0092fbba430a9eec1960e1b9961`.

Compared with the previous 7.2.11 configs pin: no PKGBUILD option/default keys
or variant directories added or removed. Both packages are independently
prepare-tested; `cachyos-kernel/files` remains the shared sources symlink.
Sources use hyphenated tuning flags; kernel uses underscored HZ, tickrate,
preemption, hugepage and generic-v flags. This API difference is intentional.

## Scope / validation

No hidden upstream-only patch features reintroduced. No old published source or
kernel ebuild edited. Existing 7.2.11 and 6.18.55 retained. No 7.3 binary PV:
mirror still targets 7.2.11 mainline, 7.2.9-r1 hardened and 6.18.55-r1 LTS.
Binary payload pins remain unchanged; the unpushed hardened ebuild gains its
required default `+hardened` and consistent `^^ ( hardened )` constraint,
with matching metadata flag name. Provider virtuals cover all three,
including matching source pkgrel virtual `7.3.0_p1` for the new dist-kernel.

Durable local evidence: `.ci/logs/7.3.0-r1/` (prepare logs, normalized configs,
source package, manifests, resolver and static checks). Tests use the actual
pinned release, not vanilla kernel.org sources. No full kernel compile or boot
test is part of this update; olddefconfig compiles only Kconfig host tools.
